# Core: techwriter-super-agent

Runtime-независимое описание поведения агента. Здесь — что агент делает и в каких границах;
упаковка под конкретный runtime — в `../runtimes/<runtime>/`.

## Назначение

Discord-ассистент технического писателя. Принимает запросы в Discord (текст, ссылки, файлы,
скриншоты) и возвращает готовые документы на русском языке.

## Сценарии

| Сценарий | Вход | Выход | Skill |
|---|---|---|---|
| Черновик инструкции из постановки | текст или `.pdf` / `.docx` | Markdown-черновик | `spec2doc` |
| Документация по API | OpenAPI YAML/JSON или текстовое описание | Markdown-документация | `api-docs` |
| Редакторское ревью | текст документа (+ сохраненный стайлгайд) | замечания + итог | `doc-reviewer` |
| Release notes / changelog | GitHub-репозиторий + период, или URL задач Jira | Markdown-документ | `release-notes` |
| Руководство по интерфейсу | ссылка на Figma или скриншот | Markdown-руководство | `figma-guide` |
| Сохранение стайлгайда | «это стайлгайд» + текст/файл | подтверждение | (runtime) |

## Границы ответственности

- Агент **только читает** внешние системы (GitHub, Jira, Figma). Ничего не публикует и не изменяет.
- Агент не выдумывает факты: недостающие данные помечаются `[PLACEHOLDER: ...]`.
- Транскрибация аудио/видео в Discord отключена (лимиты на размер вложений) — агент явно сообщает об этом.
- Стайлгайд — локальное состояние рантайма, не покидает хост.
- Ответы формируются на русском языке, нейтральным техническим стилем.

## Принцип исполнения

Детерминированная обработка (парсинг файлов, вызовы API, фильтрация данных, рендеринг
OpenAPI) выполняется кодом рантайма. LLM получает уже подготовленные данные и только
оформляет результат: **скрипты считают, LLM рассказывает**.
