# api-docs

## Продуктовый контракт

- Вход: OpenAPI YAML/JSON (текстом или файлом `.yaml` / `.yml` / `.json`) или свободное описание API.
- Выход: Markdown-документация на русском языке: эндпоинты, параметры, тело запроса, пример ответа, коды ответов.

## Правила

1. Валидная OpenAPI-спецификация рендерится локально и детерминированно (`hermes/app/skills/api_docs.py::render_openapi_docs`) — без вызова LLM. LLM не «переписывает» спецификацию.
2. LLM-путь используется только для неструктурированного описания; системный промпт — из `instructions.md`.
3. HTTP-методы, URL, имена параметров, заголовков, полей и примеры значений сохраняются без изменений.
4. Если данных не хватает — `[PLACEHOLDER: уточнить]`, а не выдуманные детали.

## Файлы

- `instructions.md` — живой системный промпт, используется рантаймом.
- `references/draft-detailed-prompt.md` — детальный legacy-промпт (черновик, не используется рантаймом).
