# doc-reviewer

## Продуктовый контракт

- Вход: текст документации для ревью (route `review`).
- Выход: замечания по разделам в формате «+ что хорошо / - что исправить / Рекомендация» и итоговая строка `Итог: X критичных / Y важных / Z рекомендаций`.
- Стайлгайд опционален: если пользователь сохранил его командой «это стайлгайд», он применяется к каждому ревью.

## Правила

1. Документ не переписывается целиком; факты, отсутствующие во входных данных, не добавляются.
2. Системный промпт загружается из `instructions.md`; ответ очищается от Markdown-разметки (`hermes/app/skills/reviewer.py::_clean_markdown`).
3. Стайлгайд — локальное состояние рантайма (`hermes/state/styleguide.md`, вне пакета и вне git).

## Файлы

- `instructions.md` — живой системный промпт, используется рантаймом.
- `references/draft-detailed-prompt.md` — детальный legacy-промпт (черновик, не используется рантаймом).
