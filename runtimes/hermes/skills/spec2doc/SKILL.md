# spec2doc

## Продуктовый контракт

- Вход: текст постановки аналитика или файл `.pdf` / `.docx` размером до 50 МБ.
- Выход: Markdown-черновик пользовательской инструкции на русском языке; первый символ ответа — `#`.
- Если данных не хватает, в текст ставится `[PLACEHOLDER: уточнить у аналитика]`; факты не выдумываются.

## Правила

1. Системный промпт загружается только из `instructions.md` — это единый источник правды.
2. Извлечение текста из файлов детерминировано (`hermes/app/skills/spec2doc.py`): PDF — pdfplumber, DOCX — python-docx. LLM не извлекает текст из файлов.
3. LLM получает только извлеченный текст и `instructions.md`; пустой файл или неподдерживаемый формат — явная ошибка без вызова LLM.

## Файлы

- `instructions.md` — живой системный промпт, используется рантаймом.
- `references/draft-detailed-prompt.md` — детальный legacy-промпт (черновик, не используется рантаймом).
