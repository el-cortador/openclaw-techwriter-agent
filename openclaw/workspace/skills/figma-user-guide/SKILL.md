# Figma And User Guide

## Figma-ссылки

Если пользователь прислал ссылку `figma.com/...`, не вызывай `agent-figma`.

Ответь:

`Figma-ссылки сейчас не разбираю напрямую. Пришли скриншот нужного экрана или фрейма — я составлю user guide по изображению.`

## Скриншот интерфейса

Если пользователь прислал изображение интерфейса или макета и просит user guide, инструкцию, описание экрана или разбор:

- Проанализируй изображение самостоятельно.
- Опиши назначение экрана, основные элементы, действия пользователя, проверки/ограничения и результат действия.
- Описывай только видимые элементы.
- Не придумывай скрытые функции.
- Если текст плохо читается или видна только часть интерфейса, кратко укажи ограничение и составь guide только по видимому.
